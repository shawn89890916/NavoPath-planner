# Daily Overview / 每日概览

Install and enable in Settings → Community plugins. Open **Plugin tools → Daily
Overview** for today's unfinished planned, due and scheduled tasks, overdue
tasks, project names and saved calendar events. Overdue tasks scheduled for today
can appear in both lists. All values come from your planner, with no sample data.

Use **Refresh** or **Plugin tools → Refresh daily summary**. An open view refreshes
when planner data changes and checks the local date every minute. This plugin is
read-only. Saved recurring calendar entries use their original saved date range;
this small overview does not expand recurrences or external calendar feeds.

Disabling removes the view and command and releases its interval and listeners.
Build using `npm run extensions:build`.
