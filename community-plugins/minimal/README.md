# Minimal

Crisp neutral paper and slate ink with a restrained, distraction-free light and dark palette.

CSS-only NavoPath theme for desktop, web and mobile. The preset follows the app's light/dark setting and exposes independent paper and ink colors for both modes. It preserves shared task geometry, keyboard focus, reduced motion and project annotations. No JavaScript executes.

Install from Appearance → Browse themes, or import the generated `public/extensions/packages/minimal.navopackage.json` file. Select the theme after installation.

`preview.png` is an actual light-mode NavoPath Execute workspace screenshot captured from the isolated product demo with this preset's default CSS. It contains example data. The package bundles the image; the catalog also serves the same bytes for preview before installation.
