# Sage

Soft sage paper, forest ink and quiet botanical annotations, paired with a neutral charcoal night palette.

CSS-only NavoPath theme for desktop, web and mobile. The preset follows the app's light/dark setting and exposes independent paper and ink colors for both modes. The shared palette covers the workspace, timeline, candidate tasks, settings, overlays and default desktop widget appearance. Saved accent, typography and widget choices retain their precedence. Shared task geometry, keyboard focus, reduced motion and project annotations are preserved. No JavaScript executes.

Install from Appearance → Browse themes, or import the generated `public/extensions/packages/sage.navopackage.json` file. Select the theme after installation.

`preview-light.png` and `preview-dark.png` are actual NavoPath Execute workspace screenshots captured from the isolated product demo with this preset's default CSS and example data. The paired previews show the same workspace and task layout. The package bundles both images; the catalog serves the same bytes for preview before installation. The legacy `preview` manifest field points to the light image.
