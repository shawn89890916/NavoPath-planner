Create an installable NavoPath community theme using this CSS-only template.
Read API.md, THEME-VARIABLES.md and the manifest. NavoPathStyle.md describes
the default theme; community themes may define their own palette, typography,
spacing and layout. Support light and dark modes with
WCAG AA text contrast, focus indicators, mobile touch sizes and reduced motion.
Use CSS variables and declarative manifest options. Package CSS/assets only,
never JavaScript. Return source, README, MIT license, .navopackage.json and its
exact SHA-256, and verify changing options, disabling and switching themes.
