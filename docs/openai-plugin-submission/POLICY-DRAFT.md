## 建议加入隐私政策的事实说明

连接 NavoPath 到 ChatGPT 或 Codex 时，你通过 OAuth 授权该连接访问当前 NavoPath 账户。身份验证使用邮箱与授权状态；需要核验线上 UserInfo 是否返回已验证邮箱。

按请求调用的工具可向 OpenAI 返回项目、任务、备注、截止日期、日程块、习惯完成记录、执行与计时记录、你提供的投入度评分，以及相关设置和变更历史。完整工作区同步工具会返回更广泛的规划数据及账户关联信息。工作区事件功能可处理你主动提供的文件路径和有限内容片段；通知与后台助理功能可能产生站内通知及另行启用的邮件。

这些信息用于执行你的查询与已授权修改。插件连接的数据交换经过 NavoPath 的 Cloudflare MCP 服务和 Supabase 账户及数据库服务；返回给 ChatGPT/Codex 的内容也会由 OpenAI 按其适用服务条款、隐私政策及你的账户设置处理。

断开插件连接与删除 NavoPath 数据是不同操作。NavoPath 内的删除不能保证同步删除此前已发送到宿主对话中的内容。需要说明维护者实际提供的授权撤销方式、账户删除行为、备份和日志保留安排。

上述覆盖依据当前工具实现拟定，发布前应核对实际部署与返回字段。特别是完整同步快照、审计中的历史内容、邮箱及其他账户标识，应尽量只返回请求所需字段。
